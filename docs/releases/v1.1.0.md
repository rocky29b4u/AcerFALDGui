# AcerFALDv2 v1.1.0

Adds a Windows installer for **FaldSync / AcerFALDv2** — a clean-room Windows utility that keeps an
Acer Mini-LED monitor's local dimming engaged while HDR is on, keeps brightness and contrast
controllable in HDR, lowers the Windows SDR white level, and optionally applies a reversible gamma
2.2 correction to SDR content inside the HDR container.

Repository version **1.1.0**. The payload is unchanged from v1.0.0, byte for byte:

| Component | Version | Notes |
| --- | --- | --- |
| AcerFALDv2 (portable) | 2.2.0 | self-contained single-file exe, no .NET required |
| AcerFALDv2 installer | 2.2.0 | Inno Setup 6 wizard around the same exe |
| FaldSync UI (tray) | 1.3.0 | framework-dependent build, needs .NET 8 |
| FaldSync engine | source | console CLI and shared DDC/HDR engine |

Tested on the Acer Nitro **XV275K P5** (4K 160 Hz, Mini-LED FALD, DisplayHDR 1000).

## Highlights

- **Installer** — `AcerFALDv2-Setup-2.2.0.exe` installs to `C:\AcerFALDv2` and asks what to create:
  a **desktop shortcut**, a **Start Menu shortcut**, and **start with Windows**. All three are
  offered in the wizard and ticked by default; untick any of them and it is skipped.
- **Proper app entry** — Settings → Apps shows AcerFALDv2 2.2.0 with its icon, an uninstaller, and
  `Win+R` → `AcerFALDv2` works.
- **Settings survive** — `faldsync.json` is only written when it does not exist, so reinstalling or
  upgrading keeps brightness, contrast, input, theme and timing.
- **Clean uninstall** — shortcuts, Start Menu folder, `App Paths` key and the Apps entry are
  removed. The uninstaller asks whether to delete your saved settings, defaulting to keeping them.
- **No elevation for saving** — `Users` get write access to `C:\AcerFALDv2` only, so the app can
  write `faldsync.json` and `faldsync.log` without a UAC prompt.
- The portable zip is still attached for anyone who would rather not install.

## Download and install

**Installer** — `AcerFALDv2-Setup-2.2.0.exe`

1. Run the setup and approve the UAC prompt.
2. Pick the folder and the shortcuts you want.
3. Optional: leave **Launch AcerFALDv2** ticked on the last page.

Silent install:

```powershell
.\AcerFALDv2-Setup-2.2.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /DIR="C:\AcerFALDv2" /TASKS="desktopicon,startmenuicon,startupicon"
```

**Portable** — `AcerFALDv2-portable.zip`: extract to a writable folder and run `AcerFALDv2.exe`.

Both are unsigned, so Windows SmartScreen may report "Unknown publisher"; choose
**More info → Run anyway** if you trust the build.

### Upgrading from v1.0.0

The app itself is identical, so there is nothing to fix. If you have been running the portable
copy and want the installed one instead, install first and then copy your `faldsync.json` into
`C:\AcerFALDv2\` — the installer never overwrites an existing configuration. Delete the old
portable folder when you are done; nothing was registered for it.

If you only use the portable zip, you can skip this release entirely.

## Requirements

- Windows 10 1809 or later, x64, for the installer. The app runs on Windows 10/11 x64.
- Administrator rights to install; none to use the app afterwards.
- A monitor with DDC/CI (MCCS) enabled in its OSD.
- For source builds only: the .NET 8 SDK. The shipped builds need no runtime.

## Known limits

- Local dimming on this panel needs **an HDR signal and the monitor's HDR display mode**. True
  SDR-signal FALD is not available on the current firmware.
- While the panel is showing another input, DDC/CI over this PC's cable may stop answering
  completely. No software can force the switch back in that state; use the monitor joystick. The
  app reconnects automatically when the panel returns.
- FALD zone-response speed is fixed by P5 firmware. There is no Adaptive Dimming DDC control.
- The gamma correction uses the AMD `SetDeviceGammaRamp` curve; an NVIDIA-specific path is not
  implemented.
- The installed exe is writable by every local user, because the app saves next to itself. On a
  shared machine use the portable zip in a per-user folder instead.
- Live input switching is not exercised in automated tests because it would drop this PC's
  DisplayPort signal.
