# AcerFALDGui v1.2.0

First public release. **AcerFALDGui** is the repository; **AcerFALDv2 2.2.0** is the app inside it.

A clean-room Windows utility that keeps an Acer Mini-LED monitor's **local dimming** engaged while
HDR is on, keeps **brightness and contrast controllable in HDR**, lowers the **Windows SDR white
level**, and optionally applies a reversible **gamma 2.2** correction to SDR content inside the HDR
container — the things the Acer Display Widget does not do. It also controls the monitor's
**speaker volume** and **input source** over DDC/CI, and ships a dark-first tray UI with a working
light theme.

Target hardware: Acer Nitro **XV275K P5** (4K 160 Hz, Mini-LED FALD, DisplayHDR 1000).

## Highlights

- **HDR + FALD automation** — forced User → HDR transition, settle and verification,
  brightness/contrast control while HDR is on, and restore to the SDR User preset.
- **Comfortable SDR on a bright panel** — Windows SDR content white from 80 to 480 nits in 4-nit
  steps, plus an optional, reversible gamma 2.2 scanout correction.
- **Dark-first tray UI** — light/dark switch, debounced sliders, HDR and gamma toggles,
  re-apply/restore actions, minimize-to-tray and saved settings.
- **Monitor volume and input** — speaker volume over VCP `0x62`; DP, HDMI 1, HDMI 2 and DP ALT over
  VCP `0x60`.
- **App-managed auto-switch** — re-selects the chosen input after startup or wake only when the
  panel reports a different one. The monitor's own Auto Source stays OSD-only.
- **OSD/DDC sync** — brightness, contrast, volume and input changed with the monitor's joystick are
  read back every 2.5 s, and a stale DDC handle after an input change is re-acquired automatically.
- **Installable or portable** — a setup wizard that installs to `C:\AcerFALDv2`, or a zip with no
  installation at all. Both are self-contained; no .NET runtime is required.

## Download and install

**Installer (recommended)** — `AcerFALDv2-Setup-2.2.0.exe`

1. Run the setup and approve the UAC prompt (it writes to `C:\` and to `HKLM`).
2. Choose the folder, then tick the shortcuts you want: **desktop**, **Start Menu** and
   **start with Windows**. All three are offered in the wizard and all three start ticked.
3. Uninstall from **Settings → Apps → Installed apps → AcerFALDv2**.

The installer defaults to `C:\AcerFALDv2` — a folder of its own, not the drive root — and gives
`Users` write access to that folder only, because the app saves `faldsync.json` and `faldsync.log`
next to its exe. Silent install:

```powershell
.\AcerFALDv2-Setup-2.2.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /DIR="C:\AcerFALDv2" /TASKS="desktopicon,startmenuicon,startupicon"
```

**Portable** — `AcerFALDv2-portable.zip`: extract to a folder you can write to and run
`AcerFALDv2.exe`. To start it at login, put a shortcut in `shell:startup`.

Both are unsigned, so Windows SmartScreen may report "Unknown publisher"; choose
**More info → Run anyway** if you trust the build.

## Requirements

- Windows 10 1809 or later, x64, for the installer. The app runs on Windows 10/11 x64.
- Administrator rights to install; none to use the app afterwards.
- A monitor with DDC/CI (MCCS) enabled in its OSD. Tested on the XV275K P5; other MCCS monitors may
  work but are not verified.
- For source builds only: the .NET 8 SDK.

## Known limits

- Local dimming on this panel needs **an HDR signal and the monitor's HDR display mode**. True
  SDR-signal FALD is not available on the current firmware.
- While the panel is showing another input, DDC/CI over this PC's cable may stop answering
  completely. No software can force the switch back in that state; use the monitor joystick. The
  app reconnects automatically when the panel returns.
- FALD zone-response speed is fixed by P5 firmware. There is no Adaptive Dimming DDC control.
- The gamma correction uses the AMD `SetDeviceGammaRamp` curve; an NVIDIA-specific path is not
  implemented.
- Do not run AcerFALDv2 together with Acer Display Widget, TwinkleTray or the original FaldSync UI.
  They drive the same DDC/CI channel and will fight over brightness and picture-mode writes.
- The installed exe is writable by every local user, because the app saves next to itself. On a
  shared machine use the portable zip in a per-user folder instead.
- Live input switching is not exercised in automated tests because it would drop this PC's
  DisplayPort signal.

Clean-room implementation: the shipped build contains no Acer binaries, logos, assets or decompiled
vendor code. Reference screenshots of the vendor UI were used during analysis only; they were never
shipped and are not part of this repository. Not affiliated with or endorsed by Acer.

## Upgrading from an earlier build

The application binaries are unchanged from v1.1.0. If you already have the portable copy, keep
using it, or install this release and copy your `faldsync.json` into `C:\AcerFALDv2\` — the
installer never overwrites an existing configuration.
