# AcerFALDGui v1.3.0

The app now has a face. **AcerFALDv2 2.3.0** ships with an icon, so the exe, the shortcuts, the
taskbar, Alt-Tab, the tray area and the setup program no longer show the generic .NET placeholder.
Nothing about the HDR/FALD behaviour changed.

![AcerFALDGui icon](https://raw.githubusercontent.com/rocky29b4u/AcerFALDGui/main/installer/AcerFALDGui-256.png)

## What the icon is

A dark tile holding a monitor whose panel is lit only in the middle — the local-dimming behaviour
this app exists for — in the app's own palette with Acer's brand green.

It is **original artwork drawn from code** by `installer/make-icon.ps1`, not the Acer logo, not a
vendor icon, and not traced from either. The icon file carries nine sizes (16, 20, 24, 32, 40, 48,
64, 128 and 256 px), and the window and tray read the size Windows asks for rather than scaling one
bitmap, so it stays sharp at 125%, 150% and 200% scaling.

## Download

| File | What it is |
| --- | --- |
| `AcerFALDv2-Setup-2.3.0.exe` | Windows installer, self-contained, installs to `C:\AcerFALDv2` |
| `AcerFALDv2-portable.zip` | the same app as a zip, no installation |

**Install** — run the setup and approve UAC (it writes to `C:\` and `HKLM`), choose the folder, then
tick the shortcuts you want: **desktop**, **Start Menu**, **start with Windows**. All three start
ticked. Silent install:

```powershell
.\AcerFALDv2-Setup-2.3.0.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART `
  /DIR="C:\AcerFALDv2" /TASKS="desktopicon,startmenuicon,startupicon"
```

Uninstall from **Settings → Apps → Installed apps → AcerFALDv2**; your settings are kept unless you
answer Yes to the question at uninstall time.

**Portable** — extract `AcerFALDv2-portable.zip` to a folder you can write to and run
`AcerFALDv2.exe`. To start it at login, put a shortcut to the exe in `shell:startup`.

Both files are unsigned, so Windows SmartScreen may say "Unknown publisher"; choose
**More info → Run anyway** if you trust the build.

## Upgrading

Install over the previous version as usual. The installer replaces `AcerFALDv2.exe` and
`README.txt`, keeps your existing `faldsync.json`, and leaves your shortcut choices as they were.
The portable zip can simply be extracted over the old folder; keep your `faldsync.json`.

## Requirements and known limits

- Windows 10 1809 or later, x64, for the installer; the app runs on Windows 10/11 x64.
- Administrator rights to install, none to use the app afterwards.
- A monitor with DDC/CI (MCCS) enabled in its OSD. Tested on the Acer Nitro XV275K P5; other MCCS
  monitors may work but are not verified.
- Local dimming on this panel needs **an HDR signal and the monitor's HDR display mode**. True
  SDR-signal FALD is not available on the current firmware.
- While the panel is showing another input, DDC/CI over this PC's cable may stop answering
  completely. No software can force the switch back in that state; use the monitor joystick. The
  app reconnects automatically when the panel returns.
- Do not run AcerFALDv2 together with Acer Display Widget, TwinkleTray or the original FaldSync UI.
  They drive the same DDC/CI channel and will fight over brightness and picture-mode writes.
- The installed exe is writable by every local user, because the app saves next to itself. On a
  shared machine use the portable zip in a per-user folder instead.

Clean-room implementation: the shipped build contains no Acer binaries, logos, assets or decompiled
vendor code, and the icon is original artwork rather than the Acer logo. Not affiliated with or
endorsed by Acer.
